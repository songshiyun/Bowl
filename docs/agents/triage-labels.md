# Triage Labels

The skills speak in terms of five canonical triage roles. This file maps those roles to the actual label strings used in this repo's issue tracker.

| Label in mattpocock/skills | Label in our tracker | Meaning                                  | Linear Label ID |
| -------------------------- | -------------------- | ---------------------------------------- | --------------- |
| `needs-triage`             | `needs-triage`       | Maintainer needs to evaluate this issue  | `0a5b0501-11d9-41b3-bc90-f374784bc374` |
| `needs-info`               | `needs-info`         | Waiting on reporter for more information | `3bf7f3f6-864d-418e-9ebb-547b6a1487db` |
| `ready-for-agent`          | `ready-for-agent`    | Fully specified, ready for an AFK agent  | `a0cd6feb-0605-4f5a-a72e-352217b534fb` |
| `ready-for-human`          | `ready-for-human`    | Requires human implementation            | `6b26aec5-fd80-481d-b622-840a0637e8da` |
| `wontfix`                  | `wontfix`            | Will not be actioned                     | `7536401b-7f19-45bf-9645-4422f577d8d2` |

When a skill mentions a role (e.g. "apply the AFK-ready triage label"), use the corresponding label string from this table.
